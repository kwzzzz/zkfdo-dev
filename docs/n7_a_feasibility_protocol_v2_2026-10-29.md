# A inference 원본 준비 가능성 시험 v2

2026-10-29. [v1](n7_a_feasibility_protocol_2026-10-29.md)의 대상·입력·도구·120초/10 GiB/디스크 관문과 원본 SHA 대조를 유지한다. v1 첫 실행은 Circom O0 컴파일과 기존 R1CS SHA 일치까지 성공한 뒤, **합성 10,000제약 상한이 있는 파서**가 큰 원본의 401,664제약 헤더를 거부했다. v1 실행과 오류 영수증은 보존한다.

v2는 저장소의 일반 `n6_j1_base_inputs.read_r1cs_shape()`로 헤더의 제약 수만 읽는다. 원본 제약식을 Python으로 적재하지 않는다. 새 worker·계획 SHA와 새 출력 폴더를 사용한다. 이 시험은 여전히 A 개발 원본의 준비·검증 운영 확인이며 W/S+J 효능 비교가 아니다.
