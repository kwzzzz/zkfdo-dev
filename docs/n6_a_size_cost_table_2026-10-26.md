## S 후보의 J: 엄격층과 탐색층

탐색층은 구성 입력을 사용한 재측정이다. 엄격층과 별도 칸으로 유지한다.

판정 칸: **계획 요청/완료; 버그 위치 L1/다른 위치 L1/위치 미귀속 L1/위치 모호 L1/배제/모름; 준비 실패·실행 실패·대기**. 개수 단위는 요청이며 고유 버그 수가 아니다. 고정 위치 매핑이 없으면 L1을 '다른 곳'으로 추정하지 않고 미귀속에 둔다. 위치별 L1은 한 요청에서 겹칠 수 있다. L1→배제→모름 순서는 기존 A 요청 집계와 같고, ANY 배제는 모든 클래스 배제를 뜻하지 않는다. 시간 칸은 기록된 요청 시간의 합/중앙값/최대(초), 재시도는 같은 요청에 합친다. '미확인'은 엔진의 unknown과 다르다.
