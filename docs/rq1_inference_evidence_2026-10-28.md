## 입력 복구 관문과 반론

[A-Q 결손 감사](rq1_n5_gap_2026-10-28.md)의 기준 입력 부재 13리비전·S 신호 261은 계속 미판정이다. 이번 재확인에서도 JWT는 원본 CLI의 필수 공개 테스트값 5개 부재(3리비전), Panther는 Yarn 부재(5), Query는 원본 테스트 모듈·fixture 부재(2), FromAddr는 생성 pkg·wasm-pack 부재(3)였다. Panther의 직접 테스트 우회도 검토했으나 테스트가 지정한 WASM이 모두 **133바이트 Git LFS 포인터**이고 일부 생성기 경로가 없어 원본 그대로는 통과할 수 없다. [N5의 10-10 보충](n5_evaluation_protocol_v1_2026-10-06.md#a-맥락-판정j-기준-입력-보충2026-10-10-리드-판단-j-실행-전)은 네트워크 설치 필요를 (d) 실패로 기록하고 입력·테스트 수정을 금지한다. 나중에 의존성을 설치하거나 입력을 재구성해 기존 엄격 점수를 소급해서 채우지 않는다.
