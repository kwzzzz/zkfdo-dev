# N7 방법 확대 관문: 조각 탐색과 원본 맥락 피드백

2026-10-28. **A 개발 검토다. 새 J 성과나 독립 평가 결과가 아니다.** 10월 29일은 완성 논문 발표가 아니라 현재 각도와 12월까지의 가능성을 판단받는 중간 점검이다.

## 현재 강점과 아직 빈 주장

자동 조각 퍼징과 J가 부모가 계산한 부품 입력에서 **동일 최상위 입력의 원본 O0 유효 witness 쌍**을 얻은 사례가 있다([검증 영수증과 시간](n5_next_gate_2026-10-28.md)). 같은 개발 회로에서 전체 zkFuzz를 연장한 세 seed는 후보가 없었다. 이 사례는 알려진 원인·사후 선택이며, 완전한 총비용과 ScaleCirc 전체 backend 비교, 독립 B 결과는 없다. 일반 우위나 새 고유 원인으로 세지 않는다.

## 새 아이디어를 실제 제약에 대조

1. **J 결과를 S에 되먹이기.** 원본에서 검증된 부품 경계 입력을 다음 S 탐색에 추가하고, 후보값 배제는 그 값과 호출 위치에만 적용한다. 정상 경계 입력을 강제하면 원본의 악의적 내부 witness를 놓칠 수 있으므로 자유 탐색도 남겨야 한다. 정상 witness의 경계 투영은 이미 [NB-01](../reports/n4-1-normal-boundary-replay-2026-10-02/REPORT.md)에서 45/45 작동했다. 그러나 단순 seed와 대상 선택은 [zkFuzz의 기존 입력 생성·설정](https://github.com/Koukyosyumei/zkFuzz#-fuzzing-with-program-mutation), [ScaleCirc의 구성·전파](scalecirc_primary_comparison_2026-10-28.md), 일반 [조합 퍼징](https://arxiv.org/abs/1903.02981)과 겹친다. **J가 줄 수 있는 새로운 정보가 실제 탐색 결과를 바꾸어야** 방법 주장 후보가 된다.
2. **배제 제약을 부품 경계에 학습하기.** 실측 점검으로 이 가설을 바로 제한했다. [inference 원본 O0 R1CS](../runs/n5-equal-cost-2026-10-28/o0-pair/compile/circuit.r1cs)(SHA-256 `7efa0199e5da19cbdb1ca503ff35fbaaed69d8757d79a96fe159096ac44880c5`)의 401,664개 제약을 한 번 훑었다. `main.response_time_normalized_fn[0].division`의 `out`, `in[0]`, `in[1]`은 원본 [SYM](../runs/n5-equal-cost-2026-10-28/o0-pair/compile/circuit.sym)(SHA-256 `6eecf15837ca1b918f890ef9f04e1becfb138294a16c5d343431d7948d0a6ed4`)에서 wire 160872–160874다. 0이 아닌 계수를 가진 신호 기준으로, 이 세 wire 중 하나를 포함한 제약은 **7개**, 세 wire와 상수만 포함한 제약은 **0개**였다. 7개 모두 부모 또는 자식 내부 wire를 함께 썼다(0부터 162564·162565·162567·162568·162656·162659·162661). 따라서 이 **한 호출**에는 ‘경계 wire만 쓰는 원본 제약을 추출’하는 규칙이 얻을 것이 없다. 내부 wire를 없앤 경계 불변식을 자동 합성했다는 뜻도 아니다.
3. **부모 한 단계 제약을 조각에 추가하기.** 상위 wire를 자유롭게 두면 안전한 과대근사가 가능하지만, 계산된 입력의 실제 범위를 좁히지 못할 수 있다. 깊이를 늘리는 정제는 기존 J의 상위 경로 수리와 CEGAR 선행에 겹친다. 이 사례에서 먼저 구현할 성과 근거는 아직 없다.
4. **후보값 대신 부품 출력 위반 술어 탐색.** 기존 J의 `LessThan` 경로도 후보값과 위반 조건을 분리한다. 새 MAdd 술어는 합성 부모에서만 도달했고 실제 A 원본의 추가 도달·배제는 0이었다([후속 보고](../runs/j-boost-2026-10-27/step5/continuation/report_20261028.md)). 더 큰 SMT 질의부터 반복하지 않는다.

외부 검토와 두 차례 반박을 교환했다. 첫 제안인 경계 제약 학습은 위 0/7 실측과 투영 문제를 제시한 뒤 철회됐다. 1-hop 및 동적 확대도 기존 방법과 겹친다는 데 동의했다. 검토 측은 현 시점의 동일 총비용·독립 평가를 우선하자고 했고, 나도 **지금 방법 개선의 효과를 예고할 수 없다는 점**에 동의한다. 다만 한 호출의 0/7로 모든 호출의 피드백 가능성을 부정하지는 않는다.

**방법 개발 재개 관문:** 독립 평가나 사전 선정 A에서 검증 비용 대부분이 맥락 미판정·정확 후보 배제에 쓰이고, 작은 같은 예산 비교에서 J 피드백이 정상 seed만 추가한 군보다 원본 검증 결과 또는 총비용을 개선해야 한다. 그렇지 않으면 기존 자동 조각 퍼징과 검증 계약의 시스템 기여로 주장을 좁힌다. 이 관문은 미래 계획이지 달성된 결과가 아니다.
