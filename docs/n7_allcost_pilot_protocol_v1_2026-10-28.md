# 전체 비용 계측 운영 시범 v1

2026-10-28. **합성 회로의 실행기 개발 시험이다. 탐지 우위·고유 원인 증가·N5 독립 성과를 평가하지 않는다.** 결과 실행 전에 이 문서와 소스·도구·군 순서의 SHA를 새 계획 JSON에 고정한다. 기존 N5와 과거 결과는 변경하지 않는다.

목표는 [비용 감사](n7_cost_cause_audit_2026-10-28.md)에서 누락됐던 후보 목록·요청 생성 등을 포함하여, 준비 시작부터 원본 검증까지 한 시간 상한으로 계측하는 것이다. J→S 피드백은 사용하지 않는다.

|---|---|
| 대상 | 기존 합성 fixture `entrypoint_violation`, `compatible_no_top_violation_observed`의 새 사본. 제약 1,000개 이하를 실제 O0에서 확인한다. 원본 fixture는 변경하지 않고 사본 pragma만 2.2.3→2.2.1로 맞춘다. |
| 군·반복 | W, 자동 S+J; seed 2026102801/02/03. fixture별 W→S / S→W / W→S 순서, 총 12군을 순차 실행한다. |
| 기계 시간 | 군마다 30초. 감독기가 원본 복사 전 `t0`를 정하고 전체 worker·관측한 후손을 감독한다. 준비·원본 기준 입력 확인·자동 조각 발견·준비·small-first 계획·전처리·퍼징·후보 목록·요청 생성·J·결과 확인을 포함한다. |

원본 복사·컴파일·후보 목록과 요청 생성은 각 단계별 시간과 전체 시간에 기록한다. 단계 시간을 전체에 다시 더하지 않는다. 최종 영수증 저장과 종료 회수 시간은 별도 꼬리 시간으로 보고하고, 마감 뒤 결과를 예산 내 성과로 옮기지 않는다. 외부 감독 호출의 전체 시간도 남긴다.

감독기는 시작 handshake와 PID·프로세스 시작 시각 확인 뒤 후손을 추적한다. 별도 세션 손자도 관측되면 회수한다. 폴링 사이 생성·세션 변경·고아화가 모두 끝난 미관측 프로세스, SIGKILL, 지속적인 ps 접근 장애까지 완전한 회수를 보장하지 않는다. `cleanup_complete=false`이면 다음 군을 실행하지 않는다.

실제 회로 전에 정상 종료·시간 초과·별도 세션 손자 회수·출력 경로 거부를 작은 프로세스로 검사한다. 운영 통과 조건은 자동 발견한 S 대상의 자연 후보 전달, 원본 검증, 영향이 없는 자식 후보의 비-L1, 단계별 기록, 마감 후 잔존 프로세스 없음이다. 자연 후보가 안 나오면 수동 후보로 성공을 만들지 않는다. 실패 시 원본 로그를 보존하고 원인 수정 후 새 계획 판으로 재시험한다. 고정한 시범 성공 조건을 발견 수에 맞춰 바꾸지 않는다.

시범이 통과해도 큰 A 효능 실험은 별도 계획이 필요하다. 그 계획에서는 탐색/J 전환과 유휴 시간 활용, 방법·seed별 총시간, 후보 검토 순서와 공통 준비 처리, 사람 검토 한도와 소스 메커니즘별 원인 중복 제거를 먼저 정한다. A는 결과를 본 개발 사례로 남고, 독립 평가 자료의 추가 실행은 기존 N5와 채택 개정을 따른다.
