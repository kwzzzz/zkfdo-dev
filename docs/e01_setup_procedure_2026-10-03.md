2. **자동 setup:** circuit 경로를 포함하는 가장 가까운 package root 또는 명시적 workspace root를 결정한다. lockfile과 `packageManager`에 맞춰 npm workspace는 `npm ci`(lockfile 부재 시 `npm install`), Yarn Classic은 `yarn install --frozen-lockfile`, Yarn Berry 2+는 선언된 고정 버전의 외부 `@yarnpkg/cli-dist`로 `yarn install --immutable`, pnpm은 선언 버전으로 `pnpm install --frozen-lockfile`을 실행한다. npm/pnpm/Yarn 모두 CLI 옵션과 격리 환경에서 lifecycle script를 끄며, Yarn Berry는 `enableScripts=false`, pnpm은 pnpmfile·manager auto-provision을 끈다. 저장소 스크립트·Corepack·프로젝트 `yarnPath`는 실행하지 않는다. 저장소별 의존성·lockfile·소스를 손으로 수선하지 않는다.
3. **submodule:** 먼저 원래 URL로 재귀 초기화를 시도한다. 실패한 SSH/SCP형 URL은 같은 host/path의 HTTPS URL로 명령별 `url.<https>.insteadOf=<original>`을 적용해 한 번 재시도한다. `.gitmodules`는 수정하지 않고 원주소·치환주소·각 시도와 비용을 기록한다. 다른 실패는 기존 유형을 보존한다.
