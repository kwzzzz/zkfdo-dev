## §1을 완료할 수 없는 이유

지정 요약의 요청 단위 술어 배제는 zkemail 두 버전 18, aq-035 12, inference 8로 합계 38이다. inference는 r-intdiv·c9221e8d·c79f42ee·loo-clamp 각각 2요청이다. 클래스 단위는 zkemail-fixed만 27로 바뀌고, 자기 배제만 있는 요청을 택하면 inference 62건이다. 어느 규칙도 지시의 18/12/20을 재현하지 않는다. 고정 A 보고서에도 50건의 명시 목록/선택 규칙이 없어 12건을 임의로 보충하지 않았다. 작성한 목록은 **미고정 초안**이며 50건 관문 완료를 주장하지 않는다.

리드의 inference 20건 요청 ID 또는 원래 집계 규칙이 필요하다. §1 목록을 구현보다 먼저 확정하라는 순서를 지키기 위해 §2는 미착수 상태다.
