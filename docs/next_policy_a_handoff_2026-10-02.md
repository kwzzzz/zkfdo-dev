# NB-01 이후 N4-1 실행 비교 관문: A-01

2026-10-02 · 담당 miiz · 버전 `policy-a-handoff-v1` · 상태: **새 범위 인계 준비, A-01 구현·실행 미착수**. [N3 채택 기록](scope_decision_accepted_2026-10-01.md)의 A안은 연구 설계로 채택됐지만 이전 착수 범위는 기록 형식만 허용했다. 이 파일은 NB-01 완료 이후의 **새 개발 범위**를 정한다. 평가 프로토콜 N5는 미고정이고, 평가 후보는 사용하지 않는다. 실제 결함 신호를 위해 [기존 P2 개발용 inference](../reports/dev-rq1-pilot-2026-09-29/README.md) 하나만 재사용한다. 이전 P2의 위치 일치 결과는 의미 검토를 통과한 원인 수가 아니다.

## 이번에 답할 질문

**통째 한 타깃과 자동 구성된 여러 타깃을 동일한 캠페인 총예산·종료 규칙으로 실제 실행하고, 조기 후보 반환 뒤 남은 예산과 실사용 자원을 신뢰할 수 있게 기록할 수 있는가?**

이 경로가 없으면 분할이 빠른지 비교할 때 한쪽은 첫 후보에서 멈추고 다른 쪽은 나머지를 도는 식으로 예산 의미가 달라진다. 조각마다 전체 예산을 새로 주거나, 남은 예산을 기록 없이 버려도 결과가 왜곡된다. 할당이 같아도 CPU·메모리 사용이 같다는 뜻은 아니다. A-01은 공정한 **실행 조건의 기계적 기반**을 만든다. 결함 탐지 우위·같은 수준 의미 검토·맥락 오탐 제거를 이번에 입증했다고 주장하지 않는다.

[NB-01](../reports/n4-1-normal-boundary-replay-2026-10-02/REPORT.md)은 정상 입력 9조건·경계 45개를 완료했다. 사전 기준과 코드의 정적 대조에서 핵심 경로는 일치했으나 [사전 기준](../reports/normal-boundary-replay-contract-2026-10-02/REVIEW.md)의 fixture 라벨/사전 경로표 변경 회귀는 정확한 형태로는 아직 없다. 이 작은 회귀 하나는 구현 담당이 보완하고 별도 결과에 기록한다. NB-01의 보존 보고서·원본 실행을 사후 변경하거나 45개를 다시 실행하지 않는다.

## 역할과 종료선

| 역할 | 범위 | 완료 증거 |
|---|---|---|
| 구현 담당 | A안 공통 캠페인 실행·계측 경로, 비보안용 결정적 실행기로 구조 검증, 그 뒤 기존 P2 inference에서 통째/분할 한 쌍의 실제 엔진 개발 실행 | 새 사전 SCOPE, 시도별·캠페인별 ledger, 의미 있는 회귀 검사, 새 결과 보고서·근거 hash. 한 쌍의 성공/실패/미지원과 모든 21조각의 시작/미시작을 기록하면 종료 |
| 독립 검토 담당 | 실행기 구현과 별도로 P2의 사전 지정된 `Subtract` 후보 하나를 같은 수준의 일반 TCCT로 검토 | 새 사전 SCOPE와 값 없는 검토 보고서. 확인/배제/미판정과 귀속 근거, 실제 검토 비용을 분리. 기존 P2와 작업 중 A-01 코드 수정 없음 |

두 작업은 병렬로 진행할 수 있다. 각 담당은 현행 계획 진행 표에서 **자신의 A-01 또는 S-01 행만** 시작·종료 상태로 갱신한다. 구현 담당만 N4 요약 행·공유 안내·근거 색인을 결과와 동기화한다. 검토 담당은 A-01 구현 중간본을 평가하지 않는다. P2 후보 검토 결과를 새 A-01 후보의 판정으로 자동 복사하지 않는다. A-01 최종 코드의 독립 스냅샷 검토는 다음 단계의 별도 좁은 작업으로 둘 수 있다.

## 구현 담당에게 전달할 프롬프트

저장소 AGENTS.md, reports/START_HERE.md, docs/plan_revision_2026-10-01.md, docs/scope_decision_accepted_2026-10-01.md, docs/next_policy_a_handoff_2026-10-02.md를 읽어라. 계획 표의 A-01 행에 담당 miiz와 시작 상태를 남긴다. 새 개발 작업 A-01의 대상·입력·예산·정책·중단 기준·도구 hash를 **실행 전에** 새 `reports/n4-1-policy-a-2026-10-02/SCOPE.md`에 기록한다. 기존 N3 채택 기록이나 고정 run/검토 원문은 수정하지 않는다.

1. 먼저 NB-01 사전 기준의 fixture 라벨과 사전 경로표 변경 회귀를 정확히 한 개의 제한된 후속 검사로 보완한다. 새 입력 연결 함수가 이 값에 의존하지 않음을 확인하고 결과를 A-01 보고서에 한 줄로 연결한다. 기존 NB-01 45경계 실험은 반복하지 않는다.
2. 기존 `experiment run`의 한 타깃 한 시도, `runner`의 wall 중심 기록, `experiment record`의 A안 표현을 확인한다. 기존 형식과 명령의 해석은 보존하고, 필요한 새 버전/경로에서 통째와 분할이 **같은 시도 실행 함수**를 쓰도록 최소 구현한다. 고정된 순서·seed·한 시도 상한·캠페인 전체 상한을 입력으로 받는다. 조각 수만큼 캠페인 총예산을 복제하지 않는다. 후보 반환 여부나 사후 검토 판정으로 캠페인 종료 규칙을 바꾸지 않으며, 정책이 정한 잔여 예산 시도를 기록한다.
3. 시도마다 할당·시작/종료 단조시각·실제 wall·CPU·메모리의 **측정된 값 또는 측정 불가 이유**·후보/미발견/시간초과/시작 실패·잔여 예산 전후·재시작 비용을 남긴다. 캠페인에는 총할당, 실제 사용, 건너뛴 시도/타깃, 종료 이유, 정책 ID, 도구/입력 hash를 남긴다. 측정 대상을 프로세스 트리/자식 프로세스로 명시하고 측정 불가 값을 0으로 쓰지 않는다. 회수되지 않은 자식과 저장 실패도 성공 처리하지 않는다.
4. 비보안용 결정적 실행기로 후보 즉시 반환·미발견·시간초과·시작 실패를 섞어 양쪽 방식의 동일 종료 규칙, 총예산 보존, 조기 후보 뒤 잔여 시도, 중복 결과 기록, 마감/취소 동작을 검증한다. 이 결과는 기계적 검증이며 탐지 성과가 아니다.
5. 구조 검사가 통과하면 [P2 설정](../reports/dev-rq1-pilot-2026-09-29/pilot-config.json)의 **기존 개발용 `inference-main` production entrypoint 한 단위**에서 통째/분할 각각 캠페인 한 번을 실제 zkFuzz로 실행한다. 기존 21개 프로젝트 조각 전부를 고정 분모에 남기고 사전 small-first 순서 하나를 사용한다. 비교를 위한 개발용 공통 총예산은 방식당 600초, 시도 상한은 30초로 고정한다. 첫 프로세스 시작부터 마지막 시도 종료까지 재시작·대기·정리 비용을 캠페인 예산에 넣고, 준비·컴파일은 별도 계측한다. 시도 결과와 무관한 다음 타깃·seed 순환 규칙, 실행 순서와 도구/소스 hash를 SCOPE에 **후보를 보기 전에** 정확히 적는다. 예산이 끝나기 전에 못 간 조각은 미시작으로 남긴다. 결과가 이전 P2와 다르거나 실제 엔진 연결이 막혀도 이유·전체 분모를 기록하고 종료한다. 새 공개 프로젝트·평가 후보로 넓히지 않는다.
6. 새 `reports/n4-1-policy-a-2026-10-02/REPORT.md`와 값 없는 evidence에 시도/캠페인 결과와 한계를 기록한다. 원시 출력은 ignored runs에 둔다. 의미 있는 회귀 검사 후 AGENTS.md의 fmt·지정 clippy·cargo test를 수행한다. 검토 담당의 사전 기준은 보존하고 실제 차단 지적만 반영한다. 현재 계획/안내/색인을 결과와 일치시킨다.

이번 완료 기준은 동일 실행 경로에서 통째/분할의 예산·종료·시도·실사용 기록을 신뢰할 수 있게 얻거나, 얻지 못한 이유를 명확히 드러내는 것이다. 실제 CPU/메모리 측정이 불가하면 자원 동등성 관문을 통과시켰다고 쓰지 않는다. 이전에 노출된 한 개발 사례의 위치 일치 후보를 검토 완료 원인이나 독립적인 탐지 우위로 세지 않는다. 기존 12시간 N4-1 담당자 작업 상한을 유지하며 과거 active-work unknown을 임의의 잔여 시간으로 환산하지 않는다. 범용 runner 재설계·새 점수·새 순위·적응형 배분은 하지 않는다. N4-1 전체·N5 상태를 자동 완료로 올리지 않는다. 문서 작성자에 도구 이름을 넣지 않고 commit/push/PR은 하지 않는다.

## 후속 분기

A-01과 P2 한 후보 검토가 끝나면 새 A-01 후보도 같은 기준으로 판정하고, 통째 후보가 없다면 그 부재를 그대로 기록한다. 이 단계의 다음 질문은 **확인된 원인당 실제 총비용과 미판정의 영향**이다. 자동 분해의 탐지 성과, 맥락 경고의 처리, 독립 평가의 주장은 그 결과와 N5 고정 뒤의 평가에서 판단한다. 현재 두 작업만으로 N4-1 전체 관문은 통과하지 않는다.
