# J→S 개발 종료와 A 비용·원인 기록 감사

2026-10-28. **결과가 알려진 inference-original A 개발 사례의 사후 감사다. 새 퍼징·J·컴파일·반사실 실험·B 원시자료 열람은 하지 않았다.** 기존 고정 프로토콜·실행 기록·판정은 보존했다.

사용자가 전달한 토론에 따라 J→S 피드백 방법 개발은 종료한다. [합성 시제품](n7_feedback_proto_2026-10-28.md)은 입력 전달과 원본 검사를 통과했지만 자유 S+J 대비 추가 원인 0이었다. 종료 근거는 이 범위의 추가 효과 부재다. J가 도달 가능한 최상위 입력과 검증 근거를 제공한 사실까지 부정하지 않는다. 이전 문서의 조건부 피드백 재시험 제안은 현재 실행 계획에서 제외한다.

## 기존 규칙과 이번 감사의 범위

[N5 §9](n5_evaluation_protocol_v1_2026-10-06.md#9-비용-기록)는 이미 준비·컴파일·캐시·실행·J·사람 검토 비용을 요구한다. §5의 동일 600초/3,600초는 **퍼징 예산**이고 J 비용은 별도다. 이번 감사가 기존 실행을 처음부터 같은 전체 시간으로 수행한 실험으로 바꾸지는 않는다. 이미 결과를 보았으므로 새 감사 규칙을 사전 등록했다고 부르지 않는다.

N5 §2는 D 개발·Q 공개 지식 노출·B 구조 준비 노출을 구분하며, 완전 미노출 S층은 비어 있다. A 수치도 논문에서 개발 사례·실패 분석으로 보고할 수 있다. 독립적인 효과 추정과 섞지 않는다. N5 전체를 통째로 독립 평가라고 부르지 않는다.

## 원인 중복 제거에서 확인된 범위

템플릿·정확한 호출 위치·속성은 **관측을 묶는 키**다. 같은 소스의 한 결함이 여러 호출·seed·출력 차이·계산 중단을 만들 수 있고, 같은 템플릿에 서로 다른 결함이 있을 수도 있다. 이 키의 개수를 고유 원인 수로 쓰지 않는다.

[기존 반사실 감사](rq1_inference_causal_review_2026-10-28.md)에서 N6 TCCT 5요청의 보존 증인은 IntDiv 출력 제약 누락이라는 **한 소스 메커니즘**에 직접 연결됐다. 술어 22요청에서는 그 보존 증인의 IntDiv 의존성만 확인했다. 다른 입력에서 같은 술어가 살아 있는지는 별개다. 나머지 16요청은 그 직접 O0 대조 밖이다. 따라서 43 L1요청 전체의 고유 원인 H는 여전히 미산정이다. 별도 L-06 입력에서 확인한 DFS의 독립 메커니즘을 N6가 새로 발견한 두 번째 원인으로 더하지 않는다.

이미 정한 [A 사후 검토 규칙](rq1_inference_causal_review_rule_2026-10-28.md)을 유지한다. 관측 표는 요청·위치·속성·입력 계약·witness를 보존하고, 원인 표는 소스 결함 식·선택 수정/LOO·동일 대표 witness 연결·다른 결함 의존성을 기록한다. 확인된 같은 메커니즘을 반복해서 세지 않으며, 미검토 부류가 남으면 확인한 부분 하한과 미검토 분모를 함께 보고한다. 새로운 L2 판정을 만들거나 기존 판정을 바꾸지 않았다.

## 다음 실행에 앞서 필요한 것

이번에 확인한 원천 기록·계측 코드에서는 위 미계측 항목을 복구할 수 없다. 새 측정값으로 과거 실제 비용을 소급 대체하지 않는다. 완전한 동일 총시간 추가 실험이 필요하면 **별도 보충 계획**에서 대상·노출 층·준비/캐시 처리·후보 판정 순서·종료 시점·사람 검토 범위를 실행 전에 고정한다. 기계 실행에는 준비부터 최종 검증까지 공통 wall 상한을 적용하고, 사람 검토는 같은 판정 절차와 별도 인시 예산으로 기록한다. N5의 기존 퍼징 예산과 채택 엔진을 바꾼 것처럼 보고하지 않는다.

B는 기존 [채택 개정](n5_amendment_b_judging_2026-10-17.md)의 평가·추가분 순서를 따른다. 이번 A 감사로 B를 선택하거나 설정을 맞추지 않았다. 현재 수행한 것은 기록 감사이며 새 대형 비교나 독립 평가 실행은 아니다.

**확인한 것:** 전처리 재사용 원본, 69 J 요청 SHA·외부 wall, 기준 입력 준비 연결, 비용 포함 관계와 부분합, 기록되지 않은 비용, 원인 귀속의 현재 범위. **추정하지 않은 것:** 완전한 총비용, 43요청 전체 H, cold 비용, 대형 회로 일반 우위와 ScaleCirc 대비 우위. 이번에는 문서와 감사 JSON만 작성했으며 실행 코드·기존 기록은 수정하지 않았다.
