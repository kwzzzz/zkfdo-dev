# zkfDO 졸업프로젝트 등록용 소개문

2026년 10월 2일 후속 설계 논의를 반영한 등록 화면용 제목 제안과 상세 설명이다. 자동 분해에서 얻은 후보를 원래 전체 회로로 연결해 확인하는 자동 맥락 검증을 핵심 기여로 발전시키는 방향을 담았다. 연구 목표와 현재 확인한 성과는 구분한다.

## 프로젝트명 제안

[블록체인특성화대학] zkfDO: 대형 영지식 증명 회로의 자동 분해 및 맥락 검증 기반 보안 분석 도구

## 상세 설명

zkfDO는 대형 영지식 증명(ZKP) 회로를 자동으로 분해해 분석하고, 조각에서 발견한 결함 후보를 원래 전체 회로에서 다시 검증하는 보안 분석 도구를 개발하는 연구 프로젝트입니다. Circom으로 작성된 회로를 대상으로, 전체 회로 분석의 시간·자원 부담과 분해 과정에서 입력 조건이나 연결 관계가 사라지는 문제를 함께 다룹니다.

결함의 위치를 미리 알려주지 않은 상태에서 분석 대상을 자동 구성하고, 기존 분석 도구인 zkFuzz로 결함 후보를 탐색합니다. 핵심은 이 후보를 원래의 입력 조건과 호출 관계에 연결해, 전체 회로의 제약을 만족하면서도 정상 계산과 다른 결과를 만들 수 있는지 자동으로 확인하는 것입니다. 이를 통해 분리된 조각의 경고를 전체 회로 수준의 검증 근거로 연결하고자 합니다.

검증 결과는 전체 회로에서의 위반 확인, 제약과 양립하지만 검사한 실행에서 최상위 위반이 관측되지 않은 경우, 특정 입력·호출 위치에서의 후보 배제, 판단 불가, 분석 준비 실패로 구분합니다. 위반을 관측하지 못한 것과 위반이 불가능함을 입증한 것을 구별하며, 후보마다 별도의 수작업 규칙을 만들지 않는 재사용 가능한 검증 절차를 연구합니다.

현재 자동 분해, 실행 관리, 컴파일 재사용과 초기 자동 맥락 검증 기능을 구현했습니다. 알려진 결함을 포함한 개발 사례에서 일부 후보가 전체 회로의 제약을 만족하면서 정상 계산과 다른 출력을 만드는 경우를 확인했습니다. 현재는 회로 내부의 중간값까지 연결할 수 있도록 입력을 역으로 구성하는 기능을 보완하고, 다른 프로젝트로의 적용 범위를 확인하고 있습니다.

향후 평가 대상과 절차를 사전에 확정한 뒤, 전체 회로를 한 번에 분석하는 방식과 동일한 시간·자원 예산에서 비교할 계획입니다. 적용 범위, 전체 회로 수준으로 확인된 결과, 미판정 비율과 검증의 신뢰성, 준비·탐색·검토를 포함한 총비용을 함께 평가합니다. 최종 목표는 대형 회로의 보안 점검에 활용할 수 있는 분석·검증 체계를 만드는 것입니다. 회로 분석, 검증 자동화, 평가 사례 구축 및 결과 검토 분야에서 협업할 수 있습니다.

## 문안의 근거

- 2026-10-02 후속 설계 논의에서 자동 맥락 확인의 재사용성·판정 의미·처리율·미판정률·총비용을 먼저 확인하고, 이를 핵심 기여로 발전시키는 경로를 정했다. 기존 계획의 자동 분해 중심 설명만으로 최신 소개 방향을 대신하지 않는다.
- [현재 연구 계획의 진행 표](plan_revision_2026-10-01.md#7-진행-표): L-01의 조건부 결과, L-02의 입력 구성 보완, C-02의 적용성 조사와 N5 미고정 상태를 구분한다. 소개문 갱신은 기존 평가 규칙이나 고정 판정을 변경하지 않는다.
- [L-01 자동 맥락 확인 결과](lifting_feasibility_results_2026-10-02.md): 자동 기능 구현과 제한된 개발 사례의 출력 차이·맥락상 배제·미판정 관측을 뒷받침한다. 모든 호출 위치·입력에 대한 보장이나 원인 귀속 결과는 아니다.
- [개발 사례 후속 검토 연결표](a02_review_status.md): 컴포넌트 검토와 전체 회로 제약·출력 차이 확인을 구분한다. 이를 새로운 고유 원인 발견이나 프로젝트의 의미적 보안 속성 위반으로 확대하지 않았다.

문안의 완료 표현은 구현 및 제한된 개발 관측에만 사용했다. 일반 성능 비교와 총비용 평가는 향후 계획으로 남겼다.
