# 전체 비용 계측 운영 시범 v2

2026-10-28. [v1 계획](n7_allcost_pilot_protocol_v1_2026-10-28.md)의 회로·도구·seed·군 순서·30초 총시간·15초 탐색 cutoff·판정 의미를 유지한다. **합성 운영 검사이며 방법의 탐지 성능 비교가 아니다.**

v1의 실제 첫 네 군 중 앞의 세 군에서 자동 후보→J 전달·원본 확인이 일어났다. 네 번째 군은 전체 회로 퍼저를 13회 재시작한 뒤 기존 v4 엔진이 `PermissionError: [Errno 1] Operation not permitted`로 불완전 ledger를 남겼다. 후보가 없었다는 결과로 세지 않는다. 반복 시도는 계측 운영 시험의 필수 조건이 아니므로 **각 군의 퍼저 시도를 최대 2회**로 고정한다. 자동 발견·원본 검증·시간 마감·캐시·나머지 v1 규칙은 그대로다.

실행기는 ledger가 `incomplete`이거나 어느 시도에서 후보 목록 필드가 빠졌으면 인프라 실패로 중단한다. J의 `preparation.status`, 후보 SHA, 원본 O0 R1CS SHA를 확인하며 준비 실패를 미검증으로 남긴다. 완전한 J 근거를 `events.jsonl`에 fsync한 뒤 읽은 시각이 30초 안인 결과만 예산 내 판정으로 센다. 이전 시범 기록·계획은 보존하고 새 코드 SHA로 새 계획 JSON을 만든다.

통과 기준은 두 fixture×세 seed×두 군이 자연 후보를 처리하고, 양성의 원본 위반과 최상위 영향이 없는 음성의 비-L1을 구분하며, 12군 모두 예산·메모리·공간·후손 정리 영수증을 남기는 것이다. 어느 단계가 막히면 이유를 기록하고 그 단계의 결과를 0건으로 대체하지 않는다. 사람 검토·고유 원인 수는 여전히 미측정이다.
